# 《请勿喧哗》网页重建起步工程 v0.1

**这是可运行的渐进式框架与模拟交互原型，并不是已经完成的情况 C 游戏。** 原 `content/story.json` 为用户给定的版本 3.5，未更改原文。随包带缩小版已有病房/深海图；完整原图及 D 的独立图层需要后续替换。本包没有 B 的真实 Python 识别程序、D 的真实 PNG 分层资源、正式 BGM 或妹妹手部动画：不应把占位内容当成已交付功能。

## 需要的软件
- 现有机器上的 Python 3（运行 `server.py` 只需标准库）；接 B 的真实视觉识别时**必须使用 B 已验证能运行 MediaPipe 的环境**，别为了网页重装或升级依赖。
- Chrome 或 Edge 浏览器。
- VS Code 或其它编辑器、Git。**不用 npm、Node、Qt、Flask。**

## 一分钟运行
```bash
cd quiet_web_starter
python server.py
```
打开 `http://127.0.0.1:8765`（若端口被占，可加 `--port 8766`）。默认界面明示【模拟输入】：点击“进入体验”→“继续：无视觉模块（模拟）”→ P（张掌）进入病房。若出现无法读取剧情，先检查是否是通过 Python 本地服务器打开，**不要双击本地 index.html**。

## 模拟测试键（正式演示时不可冒充真实识别）
- `P` PALM；`G` GOOD；`W` WAVE；`M` MOVING；`S` 静止开/关；`N` 手离开；`C` CUP 仅开发占位。
- 右上角帮助/暂停/退出长期可用，关菜单需重新满足静止；脚本和场景调试下拉支持直接检查全部九场景。
- 深海先按 `W`，再按 `S` 保持约 2～3 秒，看鱼返回；再按 `W` 重复，`S` 再次聚鱼；出现“继续剧情”后可进入返回病房。
- 终局任务提示暗去后按 `S`，有效静止满约两秒，妹妹**先伸手**，玻璃渐退；阅读字幕后按 `P` 完成最后回应。第一次进到某场景有输入防误触延迟约 0.4–0.6 秒。
- 该原型的表情/护士/门票/小鱼/妹妹动作中，有的仍以文字、Emoji 或 CSS 占位，不是正式画面。`CUP` 暂不接主线。

## 连接 B 现有 Python 程序
**先自行在终端验证 B 程序能独立运行，并确认它向 stdout 输出一行一个 JSON；stderr 只打印日志。** 本包没有 B 源码，以下 `gesture_demo.py` 只是路径示例，不保证存在：

```bash
python server.py --vision-cwd 'B程序工作目录' --vision 'B现有虚拟环境的python' 'B实际脚本路径'
```

实际命令要根据 B 的依赖、启动参数和工作目录填写。在网页“隐私与输入”页选择“同意并启动摄像头”后，服务端才会启动原 Python 进程；浏览器**不会单独调用 getUserMedia 争抢摄像头**。点击退出会终止该子进程。

可接受的已知事件有：`PALM`（可带 `x/y`）、`GOOD`、`WAVE`、`SILENCE_STATE`（带 `state=STILL|MOVING|NO_HAND`、`still_ms/motion`）、`SILENCE_REACHED`。本框架不使用一次性 `SILENCE_REACHED` 当深海自动通关；终局会在进入等待阶段后**重新累计**连续有效 STILL。输入过期不等于静止。支持 `GESTURE` 携带 `name` 的适配占位；如果 B 实际格式不完全相同，只修改 `handleInput()`，不要重写模型。

当连接真实摄像头后仍点击调试按键，界面标记已经用过辅助输入，不能把本轮算作纯真实测试。

## 开发交接与已知缺口
- 本包实现的是：9 个场景的基础入口和主流程、字幕 ID、手势模拟输入、本地 JSONL 适配入口、基本可逆鱼行为、静止防误判框架、病房/结尾完整交互逻辑占位、四音动机示范。
- 还没实现：D 的正式鱼 PNG 导入、病房窗户向海扩张的高级蒙版、护士/门票/妹妹正式局部演出、脸部动作识别、B 新 CUP 识别、真实播放器完整配乐、三位陌生玩家盲测、正式发行与现场适配。
- 关键目标：先真实接 B，再用 D 正式素材替换 Emoji 占位。不要把“原剧本文字按顺序可播放”误报为“正式演出已完成”。

完整阶段计划见包外《请勿喧哗_网页重建分阶段开发方案_v4.0.md》。


## 后端事件桥自测（不涉及真实摄像头）

此工程额外附带 `tests/fake_vision.py`，用于验证**服务器启动、事件序号、连续状态传输**；它会伪造动作事件，**不能替代 B 的真实识别或作为真实互动录屏**。

```bash
python server.py --vision python tests/fake_vision.py
```
在网页同意启动后才会执行模拟 worker。后续将 `tests/fake_vision.py` 换成 B 的真正入口。若 B 的程序需相对工作目录，附加 `--vision-cwd`。

开发界面提供 `T8盲测：关闭提示`；测试者使用该选项时不得告知按 S 的解法。正式发布须隐藏调试按钮、保留真正的帮助/辅助操作入口。
