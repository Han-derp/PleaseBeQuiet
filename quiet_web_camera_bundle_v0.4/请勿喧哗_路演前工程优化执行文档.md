# 《请勿喧哗》路演前工程优化执行文档

> **用途**：给主工程师 / 集成人员直接执行。  
> **目标**：不新增玩法，不扩展系统，只把当前核心体验做成一个**稳定、清晰、现场一眼能看懂**的演示版本。  
> **总原则**：现在的竞争力来自 **因果清晰度 × 稳定性 × 记忆点**，不是功能数量。

---

# 0. 一句话目标

最终路演时，观众必须无解释地看懂下面这条链路：

```text
玩家挥手
→ 系统明确识别成功
→ 水流增强
→ 鱼群明显逃离

玩家停止动作
→ 水流减弱
→ 一条鱼先试探回头
→ 鱼群主动靠近

终局再次停止
→ 小满先伸手
→ 停顿一个节拍
→ 玻璃才消失
```

要让观众产生的核心感受是：

> **“系统明明识别到我了，但我越努力，世界反而越远；当我停下来，世界第一次主动向我靠近。”**

# 3. 深海场景：最重要的优化

这是全项目最高优先级。

## 3.1 目标行为

深海必须形成下面的实时闭环：

```text
WAVE / MOVING
→ 水流增强
→ 鱼群远离

STILL
→ 水流减弱
→ 单鱼试探
→ 鱼群靠近

再次 MOVING
→ 鱼群重新逃离
```

必须是**可逆的**。

不能做成：

```text
进入深海
→ 等 5 秒
→ 自动聚鱼
```

也不能：

```text
第一次聚鱼后
→ 锁死鱼群
→ 后续挥手无反应
```

---

## 3.2 建议状态变量

如果当前已有等价字段，直接复用，不要重构。

```text
seaHasWaved
motionValue
silenceMode
stillMs

waterIntensity
fishProximity
specialFishState
seaGatheredOnce
```

推荐含义：

```text
waterIntensity: 0 ~ 1
fishProximity:  0 ~ 1

0 = 远离玩家
1 = 靠近玩家
```

---

## 3.3 MOVING 时反馈必须立刻出现

玩家开始挥手后：

### 0～0.2 秒

立刻出现：

- 跟手水纹
- 水流扰动
- 或手附近的视觉响应

目的：

> **先证明系统识别成功。**

不要先让鱼跑，过一会儿才出现反馈。

---

### 0.2～0.5 秒

鱼群开始明显逃离。

推荐：

```text
waterIntensity += fast
fishProximity  -= medium
```

视觉要求：

- 鱼移动方向明显
- 至少移动到肉眼能看出的距离
- 不要只移动 5～10 px
- 最好有方向统一性，看起来像“水流把鱼惊走”

---

## 3.4 静止不能立刻“全鱼回归”

推荐做成三段：

### 阶段 A：刚停止

```text
0ms ~ 500ms
```

- 水纹消失
- waterIntensity 快速下降
- 鱼暂时不回来

让玩家感觉：

> “世界突然安静了。”

---

### 阶段 B：试探

```text
500ms ~ 1200ms
```

让**一条特殊鱼 / 暖色鱼**：

- 停住
- 转头
- 向玩家移动一点

这个动作非常重要。

它把：

> “计时器触发动画”

变成：

> “世界正在观察我。”

---

### 阶段 C：群体靠近

```text
1200ms ~ 2000ms+
```

鱼群逐渐靠近。

不要瞬移。

推荐：

```text
fishProximity += slow
```

到达 2 秒附近时形成明显聚拢。

---

# 4. 输入成功反馈：必须证明“不是识别失败”

当前最大的体验风险：

玩家挥手后鱼逃走，会误以为：

> “是不是程序没识别？”

所以玩家每次有效挥手都应该得到一个非常轻量的“识别成功”反馈。

## 推荐方案

出现以下任一：

```text
WAVE ✓
```

或者：

- 手附近短暂光圈
- 水纹突然增强
- 一个 200～300ms 的 Gesture Confirm 图标

然后鱼逃离。

正确认知顺序：

```text
“它识别到了！”
↓
“等等，为什么识别成功以后鱼反而跑了？”
```

这就是“意料之外”。

错误认知顺序：

```text
“鱼怎么跑了？”
↓
“是不是识别坏了？”
```

# 5. 深海验收标准

必须连续执行至少 **10 次**：

```text
挥手
→ 鱼明显远离

停止
→ 单鱼试探
→ 鱼群靠近

再次挥手
→ 鱼再次逃离
```

### 通过条件

10 次里：

- 不误触剧情
- 不自动聚鱼
- 不出现无动作却 MOVING
- 不出现动作明显但无反馈
- 再挥后鱼一定可以重新逃离

### 不通过时修复优先级

按这个顺序修：

```text
1. 放大视觉差异
2. 放大鱼移动距离
3. 调运动/静止阈值
4. 最后才增加文字提示
```

不要先加教程。

# 6. 终局：必须做成“对方回应”，不能像开门密码

终局是第二个最重要的点。

## 6.1 正确事件顺序

必须严格保持：

```text
玩家尝试旧手势
→ 系统仍显示识别成功
→ 但剧情不推进

小满主动放下手
→ 玩家逐渐停止动作

玩家连续静止达到条件
→ 小满 / 镜中角色先伸手

停顿约 0.5～1.0 秒

→ 玻璃开始消失
→ 完整字幕 / Ending
```

---

## 6.2 禁止顺序

禁止：

```text
静止
→ 玻璃消失
→ 小满伸手
```

这会被理解成：

> “猜对密码，门开了。”

而不是：

> “我停下来以后，对方主动回应了。”

---

## 6.3 推荐时间轴

示例：

```text
t = 0.0s   SILENCE_REACHED
t = 0.1s   小满开始伸手
t = 0.8s   手到达明显位置
t = 1.0s   glassOpacity 开始下降
t = 2.0s   玻璃基本消失
```

具体数值可以按动画调整，但必须满足：

> **角色动作明显早于世界变化。**

---

# 7. 两次静止必须是两个不同意义

工程上不要只复用：

```text
silenceReached -> playSuccessAnimation()
```

建议逻辑层明确区分：

```text
SEA:
    STILL_STATE drives fish

FINAL:
    SILENCE_REACHED triggers relationship response
```

### SEA

静止 = 连续物理反馈。

### FINAL

静止 = 一次性剧情事件。

这样不会把两个场景做成完全相同的“站着不动两秒过关”。

---

# 8. 静止事件安全规则

继续保持当前输入协议原则：

```text
菜单 > 剧情手势 > 静止
```

## 必须保证

### 菜单打开

```text
SILENCE disabled
holdMs reset
gesture candidate reset
```

### 菜单关闭

建议：

```text
300ms input cooldown
```

防止菜单动作直接误触剧情。

### 场景切换

必须重置：

```text
holdMs = 0
silenceReached = false
gestureCache = empty
```

不能让深海最后一次静止直接继承到终局。

### 摄像头丢失

不能：

```text
CAMERA LOST
→ no movement
→ STILL
→ 通关
```

必须区分：

```text
STILL
NO_HAND
CAMERA_LOST
UNAVAILABLE
```

只有合法的 STILL 才能推动终局。

# 9. 技术透视 Debug Overlay

这是低成本、高收益的路演功能。

## 9.1 目的

现场证明：

> 刚才的鱼群变化和剧情不是预录动画。

---

## 9.2 建议快捷键

```text
T = Toggle Technical Overlay
```

---

## 9.3 Overlay 推荐内容

右上角半透明显示：

```text
LIVE CAMERA ●

HAND       TRACKED
GESTURE    WAVE

MOTION     0.82
STATE      MOVING
```

静止后：

```text
LIVE CAMERA ●

HAND       TRACKED
GESTURE    —

MOTION     0.04
STATE      STILL

HOLD       1.6 s
```

达到剧情边沿时：

```text
EVENT
SILENCE_REACHED ✓
```

---

## 9.4 注意

Overlay：

- 不要默认全程打开
- 不要挡主画面
- 不要展示复杂模型参数
- 不需要漂亮

最佳路演方式：

```text
先关闭 Overlay 演示惊喜
↓
完成第一次“鱼回来”
↓
主持人说：“刚才不是预录”
↓
按 T
↓
再次挥手 / 静止
↓
观众看到状态实时变化
```

# 12. 视觉节奏优化

不用新增资产也能做。

## MOVING 状态

视觉关键词：

```text
乱
快
强
远
```

例如：

- 水纹强
- 粒子运动快
- 鱼群分散
- 画面扰动更大

## STILL 状态

视觉关键词：

```text
静
慢
弱
近
```

例如：

- 水纹消失
- 粒子减速
- 小鱼回头
- 鱼群靠近
- 画面稍微恢复明亮

核心是：

> 玩家应该在身体上“感觉画面静下来了”。

# 18. 工程实现最终目标

不要追求：

> “我们还有很多功能。”

追求：

> **“这一分钟，没有任何一个动作是多余的。”**

最终观众应该亲自看到：

```text
我动
→ 世界逃开

我停
→ 世界靠近

我再次停
→ 这一次，不是世界被我控制
→ 而是另一个人主动向我伸手
```

这就是当前版本最应该被放大的竞争力。
