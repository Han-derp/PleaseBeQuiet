# 《请勿喧哗》五人岗位与 P0 交付

**共同目标：**用真实摄像头让玩家亲自体验：病房里不断出手帮助妹妹 → 深海里发现停手后鱼才靠近 → 终局停下来后小满先回应 → 玩家用手势回应她。第一停是**机制发现**；第二停是**关系变化**。不做情绪评分，不把静止包装成“手语没用”。

**剧情红线**：系统教学屏始终完整，不以“她是聋人”为客观教学句；哥哥主观便签可以让玩家误读。妹妹曾经听力受损、现已恢复，仍使用手势因为她和哥哥想继续交流；她有自己的愿望，不是只为哥哥康复而存在。终局小满必须**先**动作，玻璃**后**消失，哥哥**最后**仍用手势回应。
