# 《请勿喧哗》Web v0.3｜第一轮演出开发版

> **建议已在本机跑通 v0.2.1 的同学，使用「v0.3 增量覆盖包」直接覆盖现有工程。** 不要删除已经配置成功的 `mini-camp-main/.venv/` 与 `mini-camp-main/models/gesture_recognizer.task`，也不要重装 Python。

## 这版真正新增了什么

1. **手势交流一眼可辨**：病房和重返病房中，小满先出现带角色标识的动态手势示意；系统随后才出现「轮到你回应」；她的字幕明确标为「手势交流 · 剧情释义」，与哥哥心声、系统指令分开。已有病房静态图未改，后续可由 D 提供局部人物动作替换占位图标。
2. **重返病房有表演**：哥哥便签依次写下、划掉、改写；护士话语仍是残缺信息，同时提供小满先反应的视觉提示；她主动把两张票递出来；最后允许玩家张掌回应或直接继续。
3. **镜子不再凭空出现**：返院结束时哥哥产生一句增量独白「我应该高兴的。」；镜头继续留在同一张病房图中，左侧夜窗逐渐形成哥哥的模糊倒影，他试着张口，却仍没有说完。倒影淡去，镜头转回小满，才进入最终玻璃演出。
4. **镜子技术说明不打断剧情**：镜中暂为预制 CSS 轮廓，不调用真实面捕；说明保留在「帮助」中。允许跳过。
5. **修复转场占位 bug**：之前 `el.stage` 未注册，而且未定义有效过渡样式；本次增加真实跨场景蓝色渐隐/渐显。

`quiet_web_starter/content/story.json` **逐字节保持原版**；唯一新增独白单独放在 `quiet_web_starter/content/round1_additions.json`，不会干扰 C 正在整理的完整剧本。深海可逆鱼群、B 的 JSONL 适配与 Python 摄像头识别源代码原封不动。

## 已在 v0.2.1 跑通真实摄像头时：最简单升级方法

1. **关闭游戏服务器**：在运行它的 PowerShell 中按 `Ctrl+C`。
2. **复制备份**：把原来能玩的 `quiet_web_camera_bundle_v0.2` 文件夹复制一份，例如 `quiet_web_camera_bundle_v0.2_已验证备份`。
3. **解压「v0.3 增量覆盖包」**，把压缩包内部的 `quiet_web_starter` 文件夹拖到原来的 `quiet_web_camera_bundle_v0.2` 根目录，允许合并及覆盖同名网页文件。注意：覆盖包**不含** B 的模型、虚拟环境和摄像头程序，绝不删除这些原文件。
4. **原位置启动，不需要重装依赖**：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\start_windows.ps1
```

5. 在 Chrome/Edge 打开 `http://127.0.0.1:8765`，按 `Ctrl+Shift+R` 强制刷新（避免缓存旧的 app.js），选择同意启动摄像头。
6. 初次测试先走模拟模式或熟悉的真实输入验证病房；成功后再体验「重返病房 → 窗户镜像 → 妹妹先伸手」的新演出。

如果是全新电脑、还没有旧环境，请用**完整版 ZIP**；先完成 Python 3.12 和模型配置，随后运行包内 `setup_windows.ps1` 和 `start_windows.ps1`。

## 新一轮验收流程

- 开场：画面出现「小满先做出动作」；随后才显示「轮到你回应」。小满的对白明确标注「手势交流 · 剧情释义」；GOOD 鼓励可跳过。
- 深海：挥手鱼逃、手在镜头内静止后鱼返回；再次挥手和静止仍可逆，没手不能算有效静止。
- 重返病房：便签中「如果她不再需要我呢？」先出现，再被**看得见地划去**；妹妹响应护士的细节、递两张票皆有视觉占位。
- 镜子：不是切到陌生的深色大椭圆界面，而是原病房**左侧窗户**上的人形倒影；人物心理先有「我应该高兴的。」的铺垫。
- 最终回应：妹妹主动**放下手** → 玩家真正静止（辅助模式需主动选择）→ 她**先伸手** → 玻璃渐隐 → 阅读对白 → 玩家最终 PALM → 完整四音。
- 全程：帮助、暂停、退出正常；断流与 NO_HAND 不应视为静止；真实与模拟操作需要明显区分。

> v0.3 的动作图标仍是占位效果，**不是真实手语动画，也不宣称在教中国手语**。现阶段是让观众清楚“人物正在通过可视动作交谈”。后续 D 若提供局部抬手/放手分层素材，可在不改剧情逻辑的情况下替换。

## 开发自测（可选）

- `node quiet_web_starter/tests/test_vision_adapter.js`：原有视觉协议映射。
- `node quiet_web_starter/tests/test_round1_logic.js`：通过虚拟时钟完整回放第一轮所有剧情与模拟交互。Node 仅限开发自测，**游戏运行不需要 Node**。

**验证范围**：已执行上述非摄像头自动化测试。这里不能直接在你的 Windows 电脑上运行实体摄像头；真实手势联调请在你原本配置成功的设备上完成。
