# 《请勿喧哗》网页 v0.5：前两轮已实施

**本版基于已跑通的 v0.4；保留 B 的 `mini-camp-main` 原始识别程序与 JSONL v1 协议，保留 C 的 `content/story.json` 原文。**

## 一、已经做完的两轮

### 第一轮：剧情与场景连接
- 开场补足哥哥的经历：先学着通过动作与小满交流；事故后自己也听不见、无法开口；接回原句「今天也要照顾好她」。这些是哥哥的心声，不能当成妹妹已知的事实。
- 病房继续采用妹妹**先**主动示意、玩家 PALM 回应、可选 GOOD 鼓励、妹妹再主动邀请的原流程。现有动态动作卡是**缺少正式美术时的可用降级演出**。
- 护士从小满**看不见的方向**交流时，增强先出现视觉线索、再显示小满停下并转头的顺序。不提前替玩家揭示她听力已恢复。
- 正常流程中不进入独立 MIRROR 页面；重返病房后，窗户上的倒影直接衔接终局。为旧调试入口保留 MIRROR 兼容项，但正常试玩无需进入。
- 结尾在原 F10 后增加哥哥心声：「如果连照顾她都不需要我了……我是不是，就没有用了？」；保留妹妹先伸手、玻璃后退去、玩家最后 PALM 的顺序，并展示原来的「现在，换我等你」。不能把失聪失声等同于失去人的价值。

### 第二轮：深海交互与画面
- 普通鱼改回简洁的三尾蓝鱼 *SVG 分组*（视觉大小和配色不依赖 Windows emoji），左右运动保留可逆状态，并使用不同上下浮动相位。旧大型鱼群素材及来源仍在完整包中作备份，但运行时不引用它们。
- 独立橙色小鱼保留你提供的 `orange_front.png`，能主动前游并用缩放模拟接近镜头。
- 水纹从单圈轮廓改为错峰的三圈扩散水波＋中心晕圈；随掌心位置更新；识别流中断或无新鲜掌心坐标时不伪装为实时跟手。
- 深海初入更幽暗，鱼群聚拢后背景逐渐变亮。水纹和小鱼绘制于暗蓝遮罩之上，避免被一起压暗。
- 首次真实静止聚鱼后仍允许**主动反复**挥手与静止；无需强迫第二次静止。聚鱼后保留短暂观察时间，双手轻捧成功即进入约 3 秒的**小鱼主动游近 → 停留 → 自动返回病房**演出。期间输入不再中断成功动画。
- 顺手修复一处边界漏洞：视觉程序的 `TWO_HAND_POSE: NONE`（退出）**不会单独产生虚假的 CUP 成功**。不修改 Python 视觉判定阈值。
- 识别失败仍有明确标识的辅助捧鱼按钮和剧情跳过，绝不将它们混同于真实摄像头的成功结果。

## 二、选择正确的升级方法

**推荐：在你当前已正常运行的 v0.4 上使用【增量覆盖包】。** 不要解压一个全新的项目再配置虚拟环境。

1. 关闭当前服务器，把整个 v0.4 文件夹复制成可回退的备份。
2. 将增量 ZIP 中的 **`quiet_web_starter` 文件夹合并**到你现有项目的同名文件夹。允许覆盖网页及测试文件；不会覆盖旧的 `.venv`、模型、B 的 `camera_worker.py`。
3. 在现有项目根目录、原来的 PowerShell 中运行：

   ```powershell
   $env:PYTHON312_PATH = "D:\software\python.exe"
   powershell -NoProfile -ExecutionPolicy Bypass -File .\start_windows.ps1
   ```

4. 浏览器打开本机 `http://127.0.0.1:8765`，按 **Ctrl + Shift + R** 强制刷新。
5. 若浏览器仍显示 v0.4，关闭旧服务器、确认覆盖目录正确，避免多个 8765 服务竞争。

**完整 ZIP 供全新部署或代码审查。** 它仍不包含你电脑上单独配置的 Python `.venv` 或未随 B 原始工程上传的模型；在新目录部署需按已有成功经验恢复环境与模型。不建议为了此次升级改动这些内容。
