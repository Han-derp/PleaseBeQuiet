本目录允许后续增量放入透明 PNG；文件未交付前原代码使用 CSS 和文字图标降级演出，绝不阻塞剧情。

sister_greeting.png  小满开场主动张掌的局部特写；透明背景，建议 600x600，手及同画风袖口，放画面人物右侧。
sister_reach.png     终局妹妹主动朝哥哥伸出的手部特写；透明背景，建议 900x700，从玩家视角表现邀请，不是抓握。
nurse_silhouette.png 护士在小满视线外说话的小剪影；透明背景，建议 500x750；该素材可不做。
bedside_panel.png   床旁沟通屏底纹（透明或半透明 PNG，可选）；无图时现有 CSS 提示卡可用。
note_texture.png    哥哥的便签纹理（可选）；无图时现有 CSS 纸张卡可用。

接入方式：素材按上述精确文件名放在本目录，刷新浏览器后由 app.js 自动探测。PNG 没有时不显示破图。
