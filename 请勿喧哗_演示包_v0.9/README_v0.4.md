## 一、推荐升级步骤（Windows）

1. 关闭原本运行的游戏服务器（PowerShell 里 `Ctrl+C`），不要同时启动两个摄像头程序。
2. **先把现在能跑通的整个工程文件夹复制一份备份**，例如 `quiet_web_camera_bundle_v0.2_backup`。
3. 下载并解压本文件随附的 **v0.4 增量覆盖包**。将包内 `quiet_web_starter` 整个文件夹复制到你现有的 `quiet_web_camera_bundle_v0.2`（若你的本地父目录仍叫 v0.2）里，**合并并覆盖同名文件**。不要把它复制成 `quiet_web_starter/quiet_web_starter`。
4. 在你原本成功运行的包根目录里，沿用此前的 Python 3.12 路径和虚拟环境运行：

   ```powershell
   $env:PYTHON312_PATH = 'D:\software\python.exe'
   powershell -NoProfile -ExecutionPolicy Bypass -File .\start_windows.ps1
   ```

   如果已经建立 `.venv`，本次**不需要重新执行 `setup_windows.ps1`**。浏览器页面按 `Ctrl+Shift+R` 强制刷新。
5. 优先真实试玩：挥手 → 静止让鱼靠近 → 缓慢移动手形成“双手并列轻捧” → 看橙色小鱼游近放大。再松开双手、稍等、重新明确挥手，鱼仍应散开，再次静止仍会返回。

没有识别环境的电脑可以用 `start_sim_windows.ps1`。模拟操作为 `W` 挥手、`S` 静止、`M` 普通移动、`C` 轻捧、`X` 松开轻捧。本次新增的 `X` 用于模拟测试恢复可重复挥手。

## 三、捧鱼：当前 B 实际识别的是哪种形状？

`mini-camp-main/cupped_hands_demo.py` 对 `CUPPED_HANDS` 的判定是**镜头画面中的二维双手几何规则**，不是“真实掌心朝上、十指扣成碗状”的立体识别。请**不要**在教学图上画出算法目前未检验的严格三维捧碗动作。

适合玩家尝试的姿势：

- 两只手**都在摄像头画面内**，左右并列，尽量处于相似的高度。
- 手腕相对靠近、指尖分别向左右外侧轻轻张开，像在镜头前共同托着一个看不见的球；掌面尽量让镜头看见。
- 每只手至少有 **3 根手指处于相对伸展状态**，不要攥拳；持续稳定约 **0.4 秒**。

代码当前使用大约的二维限制：双掌中心归一化距离 `0.12–0.65`、两掌纵向差 `≤0.20`、横向距离 `≥0.08`、两食指间距/两手腕间距 `≥1.20`。这些数值来自 B 的现有代码，是其首次测试阈值，并非对所有人都保证识别。完整正确性仍需你自己实测不同距离、左右手遮挡和光照。

**重要区别**：v0.4 没有办法仅凭 B 发出的 `TWO_HAND_POSE` 状态事件进一步放宽上述视觉几何阈值，因为低于阈值的“接近成功”中间信息并没有输出。当前变更是网页端的时间容错、动作状态容错与显式辅助按钮。若今后需要真正放宽“识别范围”，必须由 B 修改、重新测试视觉算法，或新增中间数据接口。

如果姿势多次没有识别成功，聚鱼约 4.6 秒后会出现**“捧鱼识别不到？辅助靠近”**，由玩家主动点击。该方式会在顶部明确标记为辅助操作，不会伪装成摄像头识别成功，且捧鱼一直是**可选内容，不影响主线通关**。
